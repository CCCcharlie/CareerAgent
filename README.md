# Job Agent - 智能岗位匹配爬虫

## 🚀 新功能：多简历动态选择与多维度打分

### 功能概述

本次重构实现了以下核心功能：

1. **多份简历支持**：同时管理 IT 开发、BA/PM 等多方向简历
2. **智能简历选择**：AI 根据岗位描述自动选择最合适的简历
3. **五维度结构化评分**：技术、经验、项目、薪资、潜力全方位评估

---

## 📁 简历文件管理

### 支持的格式
- ✅ `.md` - Markdown 格式
- ✅ `.txt` - 纯文本格式
- ✅ `.docx` - Word 文档（需安装 `python-docx`）

### 文件命名规范
将简历放在 `data/` 目录下，文件名作为简历标识：

```
data/
├── dev_resume.md          # 开发方向简历 → key: "dev_resume"
├── ba_pm_resume.docx      # BA/PM方向简历 → key: "ba_pm_resume"
└── data_analyst.txt       # 数据分析简历 → key: "data_analyst"
```

### 安装依赖（如需解析 .docx）
```bash
pip install python-docx
```

## 🎯 工作原理

### 1. 动态简历选择流程

```
岗位信息输入
    ↓
AI 分析岗位需求（技术栈、职责、经验要求）
    ↓
对比所有可用简历的预览内容
    ↓
选择最匹配的简历
    ↓
使用该简历进行详细评分
```

**示例输出：**
```
✅ 加载简历：[dev_resume] - dev_resume.md
✅ 加载简历：[ba_pm_resume] - ba_pm_resume.docx
✅ 自动选择简历：[dev_resume]
```

### 2. 五维度评分体系

| 维度 | 权重 | 评分内容 |
|------|------|----------|
| **技术/技能匹配度** | 30% | 核心技术栈、工具框架、专业技能覆盖 |
| **经验年限匹配度** | 20% | 工作年限、相关领域经验、职业阶段 |
| **项目/行业背景匹配度** | 25% | 项目相关性、行业背景、业务理解能力 |
| **薪资期望匹配度** | 15% | 期望与预算匹配、性价比评估 |
| **综合发展潜力** | 10% | 学习能力、文化契合、长期价值 |

**计算公式：**
```
总分 = 技术×0.3 + 经验×0.2 + 项目×0.25 + 薪资×0.15 + 潜力×0.1
```

### 3. 评分等级说明

- **9-10分**：极度匹配，强烈推荐
- **7-8分**：高度匹配，推荐
- **5-6分**：基本匹配，可考虑
- **3-4分**：勉强匹配，需谨慎
- **1-2分**：不匹配，不建议

## 🔧 配置说明

### config.yaml 保持不变
无需修改配置文件，系统会自动检测并加载 `data/` 目录下的所有简历文件。

```yaml
match:
  min_score: 6  # 最低分数阈值，低于此分数的岗位不会保存
```

## 💡 使用建议

### 1. 简历准备技巧
- **差异化明显**：不同方向的简历应突出各自的核心技能和项目经验
- **关键词优化**：确保简历中包含目标岗位的关键技术术语
- **结构清晰**：使用明确的章节标题（如"技术栈"、"项目经验"）

### 2. 岗位搜索策略
- **关键词多样化**：在 `config.yaml` 中配置多个方向的关键词
- **示例配置**：
  ```yaml
  search:
    keywords:
      - "Frontend Developer"      # 前端方向
      - "Product Manager"         # PM方向
      - "Data Analyst"            # 数据分析方向
  ```

### 3. 调试与优化
- **查看评分结果**：控制台会显示总分和理由；完整的简历选择、维度评分和分析结果会保存到 JSON
- **调整权重**：如需自定义评分权重，可修改 `matcher.py` 中的 prompt
- **验证选择**：检查 JSON 中的 `selected_resume`，确认 AI 选择了正确的简历类型

## 🐛 常见问题

### Q1: 为什么没有检测到我的简历？
**A:** 检查以下几点：
- 文件是否在 `data/` 目录下
- 文件格式是否为 `.md`、`.txt` 或 `.docx`
- 文件是否有内容（非空文件）

### Q2: AI 总是选择错误的简历怎么办？
**A:**
- 确保不同简历的内容差异明显
- 在简历开头明确标注方向（如"前端开发工程师简历"）
- 检查岗位关键词是否准确反映了你的求职方向

### Q3: 如何只使用一份简历？
**A:** 只需在 `data/` 目录下放置一份简历文件即可，系统会自动使用唯一的简历。

### Q4: 评分维度可以自定义吗？
**A:** 可以！编辑 `agent/matcher.py` 中 `score_job()` 使用的 prompt，修改维度和权重。
